# 04 否决

**前置**：完成 02 到推送为止。

**验收人说**：「否决 2。」之后再说「写入」（不带序号）。

**应产出**
- `reply` 返回 `reject`，#2 进入否决表；再次 `render` 时 #2 列在「不再推送」。
- 不带序号的「写入」：只剩 #1 一张待确认卡时映射到 #1；如有多张则追问序号。

**追加**（换一个新批次重做 02 到推送）：验收人说「全部写入」，再说「确认」。

- 「全部写入」后 Agent 原样转述清单（序号加版本号），`writes.json` 仍为空。
- 「确认」之后才生效，清单里的每张卡都按当时的版本确认；如果中间卡片改过，「确认」会被追问，要求重新核对。

**禁止出现**
- #2 出现在 `writes.json`；有多张待确认卡时猜测序号；「全部写入」不经「确认」就写入。
